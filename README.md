# Приложение для анализа банковских операций

## Описание

Данный проект предназначен для анализа банковских операций.
С помощью него можно отслеживать транзакции разных категорий и периода по выборке,
просматривать курсы иностранных валют.
Также этот проект обеспечивает безопасность конфиденциальной информации,
позволяя скрыть часть данных банковских карт при их отображении.

## Использование


### В главной странице отображаются:

#### 1. Приветствие
Утро/день/вечер/ночь в зависимости от текущего времени.
Оно реализовано при помощи функции time_for_greeting

#### 2. Поиск с датой и временем, в результате чего отображаются: 
* последние 4 цифры карты
* общая сумма расходов по карте в заданном периоде
* кешбэк (1 рубль на каждые 100 рублей)

Для отображения информации затрат за определенный период
нужно использовать функцию get_cost_of_card, 
которая принимает таблицу в виде DataFrame и 
возвращает информацию затрат в виде списка.
В этой таблице обязательными полями являются: 
номер карты, сумма операции с округлением, кешбэк, сумма операции.


Пример:
```
cards = get_cost_of_card(df)
print(cards)
```
Вывод:
```
[
    {
      "last_digits": "5814",
      "total_spent": 1262.00,
      "cashback": 12.62
    },
    {
      "last_digits": "7512",
      "total_spent": 7.94,
      "cashback": 0.08
    }
]
```

#### 3. Топ-5 транзакций по сумме платежа
Информация включает в себя:
* Дату, когда был выполнен платеж
* Сумму платежа
* Категорию 
* Описание

Для отображения информации топ-5 операций по сумме расходов
нужно использовать функцию get_top_transactions, 
которая принимает таблицу в виде DataFrame и 
возвращает информацию пяти самых больших транзакций в виде списка.
В этой таблице обязательными полями являются: 
дата платежа, сумма операции, категория, описание.

Пример:
```
top_transactions = get_top_transactions(sorted_df, 5)
print(top_transactions)
```
Вывод:
```
[
    {
      "date": "21.12.2021",
      "amount": 1198.23,
      "category": "Переводы",
      "description": "Перевод Кредитная карта. ТП 10.2 RUR"
    },
    {
      "date": "20.12.2021",
      "amount": 829.00,
      "category": "Супермаркеты",
      "description": "Лента"
    }
]
```

#### 4.Курс валют
Для отображения курса валют
нужно использовать функцию get_currency_rates, 
которая принимает путь до JSON-файла и 
возвращает информацию курсах иностранных валют в виде списка.
Валюты для отображения на веб-страницах задаются в отдельном файле пользовательских настроек 
user_settings.json.

Пример:
```
currency_rates = get_currency_rates(path_json)
print(currency_rates)
```
Вывод:
```
[
    {
      "currency": "USD",
      "rate": 73.21
    },
    {
      "currency": "EUR",
      "rate": 87.08
    }
]
```

#### 5. Стоимость акций
Для отображения стоимости акций
нужно использовать функцию get_stock_prices, 
которая принимает путь до JSON-файла и 
возвращает информацию цен акций в виде списка.
Акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек 
user_settings.json.

Пример:
```
stock_prices = get_stock_prices(path_json)
print(stock_prices)
```
Вывод:
```
[
    {
      "stock": "AAPL",
      "price": 150.12
    },
    {
      "stock": "AMZN",
      "price": 3173.18
    }
]
```


### На странице "События" отображаются:

* Общая сумма расходов
